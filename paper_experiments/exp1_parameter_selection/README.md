# Exp. 1 Parameter Selection

## Purpose

Show that `kappa_top`, `tau0`, and related UW-IDVO parameters are selected systematically rather than manually guessed.

## Dataset

- AQUALOC Harbor

## Sensor Mode

- `mono`

## Methods

Usually this experiment focuses on parameter sweeps of full `IDVO`.

## Current Status

The previous paper results can still be used. New runs are optional unless the final code/config changes.
